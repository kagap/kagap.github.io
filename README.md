# Kamil Molasy — Data Portfolio

Personal portfolio site, live at **[kagap.github.io](https://kagap.github.io)**, showcasing data analytics work across Power BI, Python, SQL, R, and Tableau.

## 📄 Pages

* [`index.html`](index.html) — Power BI portfolio (home page)
* [`python.html`](python.html) — Python portfolio
* [`sql.html`](sql.html) — SQL portfolio
* [`r.html`](r.html) — R portfolio
* [`tableau.html`](tableau.html) — Tableau portfolio
* [`notebooks/`](notebooks) — Jupyter notebooks featured on the Python page

This is a static site — clone the repo and open [`index.html`](index.html) in a browser, or serve the folder with any static file server.
